---
title: "Onsite staff"
description: "Create and manage login codes for your gate, binding and top-up teams."
---

Open **Onsite Staff** in the event sidebar to manage access for event-day staff. Each person signs in with a login code, and the code's role decides what it can do.

<Note>
To invite people to your Business Portal organization instead, see [Team](/organization/team).
</Note>

<Frame>
  <img src="/images/onsite/onsite-staff-list.svg" alt="Onsite Staff list with role filter, search, Export, Add Staff and Status column" />
</Frame>

Filter by role or search by login code. **Export** downloads a CSV of what you've filtered. **Status** can be changed directly in the list.

## Add staff

Select **Add Staff**, then use one of two tabs.

### Manual Creation

<Steps>
  <Step title="Choose a role">
    Top-up staff also need a **Top-up Station**, set up in [Top-up setup](/tap/top-up-setup).
  </Step>
  <Step title="Set the number of codes">
    1 to 200, all with the same role and note (up to 200 characters).
  </Step>
  <Step title="Choose a status and select Generate Codes">
    **Active** (default) or **Inactive**.
  </Step>
</Steps>

<Frame>
  <img src="/images/onsite/onsite-staff-add-manual.svg" alt="Create Onsite Staff panel on the Manual Creation tab" />
</Frame>

### CSV Import

Use this to create codes for named people in one go. Select **Download Template** (specific to this event; keep the first four columns unchanged), fill it in, then upload it. CSV only, up to 200 records.

<Frame>
  <img src="/images/onsite/onsite-staff-add-csv.svg" alt="Create Onsite Staff panel on the CSV Import tab" />
</Frame>

<Warning>
One bad row means no codes are created. Fix the lines listed and upload again.
</Warning>

## Edit a login

Select the pencil icon to change the **Note**, **Status** or (Top-up staff) **Top-up Station**, then **Save Changes**. A role can't be changed; create a new code instead.

<Tip>
Set a code to **Inactive** to turn it off without deleting it, for example when a shift ends.
</Tip>
