Onsite Operations is the desk console for event day. Open it from **Onsite Operations** in the event sidebar. The Command Center shows whether the floor is healthy and what needs doing next.

The event type decides what is available:

- **Ticket-only event:** entry by QR scan, or manual check-in when a code won't scan. No wristbands or cashless.
- **Tap event:** entry by wristband tap only. Wristbands and Cashless workspaces appear. See [PLVR Tap](/tap/introduction).

The page refreshes itself about every 30 seconds.

## Find a guest

Type a Ticket ID, email, wristband, order number or payment/top-up reference (at least three characters) and select **Search**. The type is detected for you. Results open in [Search](/onsite/search).

## Record a problem

Select **+ New service case** to record a problem. See [Service cases](/onsite/cases).

## Summary cards and health

The cards show open service cases, tickets blocked from entry, unresolved top-ups (Tap events only) and average time to close. Select a card to open its list. If the floor isn't running normally, a banner reads **Degraded** or **Incident**; otherwise none appears.

## Attention queue

Open cases, ordered by risk and then by wait time. The first eight are shown; select **View all** for the rest. Select a row to open the case.

## Workspaces

| Workspace | Use it for | Shown |
| --- | --- | --- |
| [Tickets & Entry](/onsite/tickets) | Blocked tickets | Always |
| [Wristbands](/onsite/wristbands) | Bindings, freezes, ownership | Tap events |
| [Cashless](/onsite/cashless) | Money collected, credited, spent | Cashless enabled |
| [Guests](/onsite/guests) | Invite lists, approved additions | Always |
| [Service cases](/onsite/cases) | Everything raised at the desk | Always |

**Desk activity** counts actions recorded in the last 30 minutes. Searches aren't recorded, so it shows work done, not people seen. A **Floor alerts** panel appears only when several failures cluster, with a suggested action for each.
