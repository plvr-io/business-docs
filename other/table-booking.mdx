---
title: "Table booking"
description: "Set up your venue's bookable tables."
---

Table booking lets guests book tables. It is set up once per organization, not per event, and has two parts: **Settings** and **Tables**.

<Note>
  **Table Booking** appears in the top navigation only for owners, admins and managers.
</Note>

## Set up

<Steps>
  <Step title="Open Table Booking">
    Fill in the setup form. **Name** and **Currency** are required.
  </Step>
  <Step title="Select Create Table Booking">
    You go straight to **Tables**.
  </Step>
  <Step title="Add your tables">
    Nothing can be booked until tables exist.
  </Step>
</Steps>

## Settings

Settings cover your logo, name, currency, venue, seat map, drinks menu and rules.

{/* SCREENSHOT: images/other/table-booking-settings.png | Table Booking > Settings. Callouts: 1 Currency, 2 Venue, 3 Status, 4 Save Changes. */}

- Leave **Venue** empty to use your organization's venue. Booking times follow its timezone.
- Set **Status** (3) to Inactive to hide table booking onsite. It cannot be deleted.

<Warning>
  Changing the currency (1) does not convert existing amounts. A table priced at 500 stays 500.
</Warning>

## Tables

Each table has a default capacity and minimum spend that prefill onsite table orders; each order can change them. Tables cannot be deleted.

{/* SCREENSHOT: images/other/table-booking-tables-list.png | Table Booking > Tables with about 6 tables (A1 to A6, capacity 4, minimum spend 500). Callouts: 1 Add Tables, 2 edit pencil. */}

**Add Tables** (1) adds several at once. Fill the first row, then use **Add Row**: names count up (A1, A2) and capacity and spend carry over. Up to 100 rows at a time.

{/* SCREENSHOT: images/other/table-booking-add-tables.png | Add Tables panel with A7 (capacity 4, minimum spend 500) and an autofilled A8 row. Include the Add N Tables button. */}

- Names must be unique (ignoring capitals and spaces), up to 64 characters.
- Capacity is 1 to 100. Minimum spend cannot be negative.
- Use the pencil (2) to edit a table. Existing orders keep their own values.
