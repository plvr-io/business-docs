For whoever reconciles money and reports on how the event went. Most reports can be exported.

| Question | Where to look |
| --- | --- |
| How is the event selling? | [Events overview](/events/overview) |
| Who bought which ticket or add-on? | [Ticket report](/tickets/ticket-report) |
| How did each promo code perform? | [Promo codes](/promotions/promo-codes) |
| Which channels and campaigns brought revenue? | [Tracking links](/promotions/tracking-links), [Email campaigns](/promotions/campaigns) |
| What did each vendor sell, and what do we owe? | [Spending report](/tap/spending-report) |
| Every top-up and spend? | [Cashless activity](/tap/cashless-activity) |
| Is a top-up unresolved at the desk? | [Cashless (Onsite Operations)](/onsite/cashless) |
| Who paid a custom amount? | [Payment links](/other/payment-links) |
| Who comes back? | [Audience](/organization/audience) |

Cashless pages only appear for events that use [PLVR Tap](/tap/introduction).

## Recommended path

<Steps>
  <Step title="During sales">
    Watch the [overview](/events/overview) and export the [Ticket report](/tickets/ticket-report).
  </Step>
  <Step title="On event day">
    Follow [Cashless activity](/tap/cashless-activity) and resolve top-ups in [Cashless](/onsite/cashless).
  </Step>
  <Step title="After the event">
    Export from the [Spending report](/tap/spending-report) and review payment links.
  </Step>
  <Step title="Close out">
    Follow [After the event](/guides/after-the-event).
  </Step>
</Steps>

Managers, admins and owners can open these pages. See [Guides by team](/roles).
