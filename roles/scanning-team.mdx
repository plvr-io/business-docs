Event-day staff do not need a portal account. Whoever manages the event creates **login codes** under **Onsite Staff**, and each code has a role. Organization **Scanner** members are separate: they only use PLVR Scan. See [Team and roles](/organization/team).

## Onsite roles

{/* SCREENSHOT: images/roles/onsite-staff-add-staff-role-list.png | Onsite Staff page, Add Staff window open with the Role dropdown expanded showing all onsite roles and their descriptions. Crop to the dialog. */}

| Role | Typical job |
| --- | --- |
| Check-in staff | Admit guests at the gate. |
| Add-on check staff | Check add-ons at redemption points. |
| Binding staff | Put wristbands on guests (PLVR Tap events). |
| Top-up staff | Take top-ups at an assigned **Top-up Station**. |
| Supervisor | Handle restricted actions at the desk. |

## For the team lead

<Steps>
  <Step title="Create stations first (cashless events)">
    Top-up staff need a station. See [Top-up setup](/tap/top-up-setup).
  </Step>
  <Step title="Add staff">
    In **Onsite Staff**, select **Add Staff**. Create a batch of codes, or import named people with a CSV.
  </Step>
  <Step title="Hand out codes">
    Label each code in **Note**, such as "Alex - Main Gate".
  </Step>
  <Step title="Switch codes off after the shift">
    Set a code to **Inactive**. This keeps it without deleting it.
  </Step>
</Steps>

- **Admitting guests:** [Guests](/onsite/guests)
- **Door sales:** [Door sales](/promotions/door-sales)

- **Top-ups:** [Top-up setup](/tap/top-up-setup)
