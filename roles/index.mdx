## What each organization role can access

The owner is the person who created the organization. See [Team and roles](/organization/team) to add people or change roles.

{/* SCREENSHOT: images/roles/roles-header-as-scanner-vs-owner.png | Two header crops stacked, labelled: the portal header as an Owner (Events, Table Booking, Audience, Team, Organization all visible) and as a Manager (no Team link). Crop each to the header bar only. */}

| Header link | Owner | Admin | Manager | Scanner |
| --- | --- | --- | --- | --- |
| **Events** | Yes | Yes | Yes | Yes |
| **Audience** | Yes | Yes | Yes | Yes |
| **Table Booking** | Yes | Yes | Yes | No |
| **Organization** | Yes | Yes | Yes | No |
| **Team** | Yes | Yes | No | No |

Scanners are for ticket scanning in PLVR Scan, so most of their work happens outside the portal.

<Note>
  Gate, wristband and top-up staff at the event sign in with a login code instead. See [Onsite staff](/onsite/onsite-staff) and the [Scanning team](/roles/scanning-team).
</Note>

New to the portal? See the [Portal tour](/getting-started/portal-tour) or [Quickstart](/getting-started/quickstart). To follow the event timeline instead, see [Guides by phase](/phases).
