适用于负责对账和汇报活动成效的人。大多数报表都可以导出。

| 问题 | 查看位置 |
| --- | --- |
| 活动卖得怎么样？ | [活动概览](/zh-hans/events/overview) |
| 谁买了哪种门票或附加项？ | [门票报表](/zh-hans/tickets/ticket-report) |
| 每个优惠码的效果如何？ | [优惠码](/zh-hans/promotions/promo-codes) |
| 哪些渠道和营销活动带来了收入？ | [追踪链接](/zh-hans/promotions/tracking-links)、[邮件营销](/zh-hans/promotions/campaigns) |
| 每个商户卖了什么，我们需要结算多少？ | [消费报表](/zh-hans/tap/spending-report) |
| 每一笔充值和消费？ | [无现金动态](/zh-hans/tap/cashless-activity) |
| 服务台有未完成的充值吗？ | [无现金（Onsite Operations）](/zh-hans/onsite/cashless) |
| 谁支付了自定义金额？ | [支付链接](/zh-hans/other/payment-links) |
| 谁是回头客？ | [受众](/zh-hans/organization/audience) |

无现金相关页面仅在使用 [PLVR Tap](/zh-hans/tap/introduction) 的活动中显示。

## 推荐路径

<Steps>
  <Step title="销售期间">
    关注[概览](/zh-hans/events/overview)并导出[门票报表](/zh-hans/tickets/ticket-report)。
  </Step>
  <Step title="活动当天">
    跟踪[无现金动态](/zh-hans/tap/cashless-activity)，并在[无现金](/zh-hans/onsite/cashless)中处理充值问题。
  </Step>
  <Step title="活动结束后">
    从[消费报表](/zh-hans/tap/spending-report)导出数据，并核对支付链接。
  </Step>
  <Step title="收尾">
    按照[活动结束后](/zh-hans/guides/after-the-event)操作。
  </Step>
</Steps>

经理、管理员和所有者都可以打开这些页面。请参阅[按团队查看指南](/zh-hans/roles)。
