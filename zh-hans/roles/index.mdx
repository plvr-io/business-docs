## 各组织角色的访问权限

所有者是创建该组织的人。如需添加成员或更改角色，请参阅[团队与角色](/zh-hans/organization/team)。

{/* SCREENSHOT: images/roles/roles-header-as-scanner-vs-owner.png | Two header crops stacked, labelled: the portal header as an Owner (Events, Table Booking, Audience, Team, Organization all visible) and as a Manager (no Team link). Crop each to the header bar only. */}

| 顶部导航链接 | Owner | Admin | Manager | Scanner |
| --- | --- | --- | --- | --- |
| **Events** | 是 | 是 | 是 | 是 |
| **Audience** | 是 | 是 | 是 | 是 |
| **Table Booking** | 是 | 是 | 是 | 否 |
| **Organization** | 是 | 是 | 是 | 否 |
| **Team** | 是 | 是 | 否 | 否 |

Scanner（扫码员）角色用于在 PLVR Scan 中扫描门票，因此他们的大部分工作都在后台之外进行。

<Note>
  活动现场的入口、手环和充值工作人员改用登录码登录。请参阅[现场工作人员](/zh-hans/onsite/onsite-staff)和[扫码团队](/zh-hans/roles/scanning-team)。
</Note>

第一次使用后台？请参阅[后台导览](/zh-hans/getting-started/portal-tour)或[快速开始](/zh-hans/getting-started/quickstart)。如果想按活动时间线查看，请参阅[按阶段查看指南](/zh-hans/phases)。
