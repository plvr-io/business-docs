title: "Quickstart"
description: "From event page to first ticket sale."
---

Assumes you already have an organization. If not, start with [Onboarding](/getting-started/onboarding).

<Steps>
  <Step title="Open your event">
    Select **Events** in the header, then your event. No event yet? See [Create your first event](/getting-started/onboarding#create-your-first-event).
  </Step>
  <Step title="Build the event page">
    In **Event Editor**, review each section and select **Save Event**. See [Event editor](/events/event-editor).
  </Step>
  <Step title="Set up tickets">
    Review types and prices under **Tickets**. See [Ticket management](/tickets/ticket-management).
  </Step>
  <Step title="Set the event live">
    Choose **Public** in the status menu on the **Events** page. See [Event status](/events/overview#event-status).
  </Step>
  <Step title="Promote it">
    Share a [promo code](/promotions/promo-codes) or [tracking link](/promotions/tracking-links).
  </Step>
  <Step title="Watch sales">
    Follow the [Overview](/events/overview) and [Ticket report](/tickets/ticket-report).
  </Step>
</Steps>
