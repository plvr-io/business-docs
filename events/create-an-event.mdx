---
title: "Create an event"
description: "Set up your event page and get ready to sell tickets."
---

On **Home** or **Events**, select **Create event**. Organization owners, admins and managers can create standard ticketed events.

<Frame>
  <img
    src="/images/self-service-create-event.png"
    alt="Create event form with the mobile preview and Event info tab"
  />
</Frame>

<Steps>
  <Step title="Fill in Event info">
    - **Basics** — Enter the **Event name** and check the **Event URL**. Upload a square **Main image**. **Private** is selected by default and lets anyone with the link open the event. Choose **Public** to make the event eligible to appear in PLVR listings.
    - **Location & time** — Select the **Venue** first, then enter the session start and end time in the venue's time zone.
    - **Content, Pricing and Entry & terms** — Fill in **About**, select a **Currency**, and review **Terms and conditions**.

    Use **Fill with AI** if you have event details ready to paste. Review the fields it fills before continuing.
  </Step>
  <Step title="Review Checkout">
    **Full Name** and **Email Address** are collected automatically. Use **Booking details** to add questions, and review **Tax** and **Consent** as needed. See [Registration form](/events/registration-form).
  </Step>
  <Step title="Create the event">
    Review the **Mobile preview**, then select **Create event**. The event page goes live with the visibility you selected. You can create the event before adding tickets.
  </Step>
</Steps>

After the event is created, [Ticket Management](/tickets/ticket-management) opens so you can add tickets. To change the event page or checkout later, open [Event editor](/events/event-editor).
