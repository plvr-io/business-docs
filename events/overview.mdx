## Event list

**Events** is the first page after sign-in. Search by name, switch between **All**, **Upcoming** and **Past**, and select a row to open the event.

{/* SCREENSHOT: images/events/overview-events-list.png | Events page with at least 4 event rows of different statuses (Public, Private, Inactive, Ended). Callouts: 1 Search, 2 tabs, 3 status menu, 4 View event link. */}

Use the status menu (3) to set an event to **Public**, **Private** or **Inactive**. **Ended** events are locked.

{/* SCREENSHOT: images/events/overview-event-status-menu.png | One event row with its status menu open. Crop to the row. */}

If you have no events, creating one is not self-service yet. Contact partners@plvr.io.

## Event overview

Opening an event shows its **Overview**. Use the side menu to reach the event's other pages.

{/* SCREENSHOT: images/events/overview-summary-cards.png | An event's Overview for an event with sales, add-ons and personalization. Capture the title and all summary cards. */}

Total Revenue combines tickets, add-ons and payment links. Conversion Rate is paid orders divided by page views. Personalization Progress and Add-ons Sold appear only when they apply.

The **Trend** chart plots one measure over time. Switch between **Cumulative** and **Daily**.

{/* SCREENSHOT: images/events/overview-trend-chart.png | Trend chart with data and the measure dropdown open. Crop to the chart card. */}

**Performance Insights** splits revenue by source and sales by type: full price, promo code, or comp ticket (given directly, no checkout).

{/* SCREENSHOT: images/events/overview-performance-insights.png | Performance Insights panel for an event that used promo codes and comp tickets. Crop to the panel. */}

**Ticket Breakdown** shows sales and revenue per ticket type.

{/* SCREENSHOT: images/events/overview-ticket-breakdown-table.png | Ticket Breakdown table for an event with 3 ticket tiers. Crop to the table. */}

<Tip>
  For more detail on sales, see the [Ticket report](/tickets/ticket-report).
</Tip>
