## Your event list

{/* SCREENSHOT: images/events/overview-events-list.png | Events page showing the greeting, Search events field, All/Upcoming/Past tabs and at least 4 event rows with different statuses (Public, Private, Inactive, Ended), View event links and the Previous/Next paging. Full page. */}

**Events** is the first page you see after signing in. It opens with a greeting ("Good morning", "Good afternoon" and so on) and your organization's events underneath.

- **Search.** Type in **Search events...** to filter by event name.
- **Tabs.** Switch between **All**, **Upcoming** and **Past**.
- **Paging.** Ten events appear per page. Use **Previous** and **Next** to move through longer lists.

Each row shows the event image and name, its start date and time in the event's own time zone, a **View event** link to the public event page, a **status** menu, and the event's sales: revenue and tickets sold out of tickets available.

Select a row to open that event.

### Event status

Use the status menu on a row to change an event's status to **Public**, **Private** or **Inactive**. A confirmation "Event is now ..." appears when it updates.

{/* SCREENSHOT: images/events/overview-event-status-menu.png | One event row on the Events page with its status menu open showing Public, Private and Inactive. Crop to the row and menu. Highlight the status control. */}

An event with the status **Ended** is locked: its status menu is disabled and cannot be changed.

### No events yet

If your organization has no events, the page explains that creating an event is not self-service yet and asks you to contact partners@plvr.io. Select the address to copy it. If a search finds nothing, the page says no events match and suggests a different search.

## The event overview

Opening an event takes you to its **Overview** page: "Summary of your event performance and insights." The side menu on the left lets you move to other pages for that event.

{/* SCREENSHOT: images/events/overview-summary-cards.png | An event's Overview page (Overview in the event menu) for an event with sales, add-ons and personalization: capture the title and the full set of summary cards (Total Revenue, Tickets Sold, Personalization Progress, Add-ons Sold, Page Views, Conversion Rate). */}

### Summary cards

| Card | What it shows |
| --- | --- |
| **Total Revenue** | Revenue from tickets, add-ons and payment links combined. |
| **Tickets Sold** | Tickets sold out of the total available. |
| **Personalization Progress** | Tickets personalized out of those that need it. Only shown for events that require personalization. |
| **Add-ons Sold** | Add-ons sold out of the total. Only shown when the event has add-ons. |
| **Page Views** | How many times the event page has been viewed. |
| **Conversion Rate** | Paid orders divided by page views. |

### Trend chart

The **Trend** chart plots one measure over time. Choose the measure from the dropdown: **Revenue**, **Tickets Sold**, **Addons Sold** (when the event has add-ons), **Page Views** or **Conversion Rate**. You can switch between **Cumulative** and **Daily** views, and choose a time range: **All Time**, or a custom range. For conversion rate, the chart subtitle shows the average for the period.

{/* SCREENSHOT: images/events/overview-trend-chart.png | Overview page Trend chart with data, the measure dropdown open showing Revenue, Tickets Sold, Addons Sold etc. Crop to the chart card. */}

### Performance Insights

This panel splits your results two ways.

- **Revenue Source**: **Via Tickets**, **Via Add-ons** and **Via Payment Links**.
- **Sales Attribution**:
  - **Full Price Sales**: tickets bought at the standard listed price, including free tickets, without a promo code.
  - **Promo Sales**: tickets bought with a promo code at checkout.
  - **Comp Tickets**: complimentary tickets you gave directly to attendees, with no checkout.

### Ticket Breakdown

A table with one row per ticket type, showing **Ticket Type**, **Price**, **Sold / Total (%)**, **Composition** (full price, promo and comp) and **Revenue**, in the event's currency.
