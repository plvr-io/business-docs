## Event list

**Events** is the first page after sign-in. Search by name (1), switch between **All**, **Upcoming** and **Past** (2), and select a row to open the event. **View event** (4) opens the public event page.

<Frame>
  <img src="/images/events/overview-events-list.svg" alt="Events list with numbered callouts" />
</Frame>

Use the status menu (3) to set an event to **Public**, **Private** or **Inactive**. **Ended** events are locked.

<Frame>
  <img src="/images/events/overview-event-status-menu.svg" alt="Event status menu with Public, Private and Inactive" />
</Frame>

If you have no events, creating one is not self-service yet. Contact partners@plvr.io.

## Event overview

Opening an event shows its **Overview**. Use the side menu to reach the event's other pages.

<Frame>
  <img src="/images/events/overview-summary-cards.svg" alt="Event overview summary cards" />
</Frame>

Total Revenue combines tickets, add-ons and payment links. Conversion Rate is paid orders divided by page views. Personalization Progress and Add-ons Sold appear only when they apply.

The **Trend** chart plots one measure over time. Switch between **Cumulative** and **Daily**.

<Frame>
  <img src="/images/events/overview-trend-chart.svg" alt="Trend chart with metric menu open" />
</Frame>

**Performance Insights** splits revenue by source and sales by type: full price, promo code, or comp ticket (given directly, no checkout).

<Frame>
  <img src="/images/events/overview-performance-insights.svg" alt="Performance Insights card" />
</Frame>

**Ticket Breakdown** shows sales and revenue per ticket type.

<Frame>
  <img src="/images/events/overview-ticket-breakdown-table.svg" alt="Sales Breakdown table" />
</Frame>

<Tip>
  For more detail on sales, see the [Ticket report](/tickets/ticket-report).
</Tip>
