**RSVP** (in the event menu) is where you review requests to attend.

<Note>
  RSVP is enabled upon request.
</Note>

<Frame>
  <img src="/images/events/rsvp-page-overview.svg" alt="RSVP page with numbered callouts" />
</Frame>

Filter by **Pending**, **Approved** or **Rejected** (2). The summary card calls rejected requests "Declined"; it is the same thing.

## Approve or reject

Select **Approve** or **Reject** (3) on a pending row. With more than one ticket type, you choose the **Ticket Type** when approving. Approving needs at least one ticket type on the event.

<Frame>
  <img src="/images/events/rsvp-approve-ticket-selection.svg" alt="Approve Attendee window with the ticket type list" />
</Frame>

## Edit a status

The pencil (4) opens **Edit Attendee**. Approving requires a ticket type.

- Approved attendees cannot be edited.
- Rejected attendees can only be moved back to pending.

The book icon (4) opens that attendee's **Form Responses** from your [registration form](/events/registration-form).

<Frame>
  <img src="/images/events/rsvp-edit-attendee-window.svg" alt="Edit Attendee window with the Status menu open" />
</Frame>

<Frame>
  <img src="/images/events/rsvp-edit-attendee-ticket-type.svg" alt="Edit Attendee window with the Ticket Type menu open" />
</Frame>

## Bulk actions

Tick rows, then select **Bulk Actions** (5), choose a status (and ticket type if approving), then **Confirm**.

- Up to 50 attendees at once.
- All selected attendees must share the same status, and approved attendees cannot be selected.

<Frame>
  <img src="/images/events/rsvp-bulk-actions.svg" alt="Bulk Actions window for selected RSVPs" />
</Frame>

Select **Export CSV** (6) to download the list.
