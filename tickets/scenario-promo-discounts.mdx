**Goal:** Targeted discounts without changing public prices. Buyers enter the code at checkout. For every field see [Promo Codes](/promotions/promo-codes).

## Partner code: 10% off, 50 uses

<Steps>
  <Step title="Create the code">
    In [Promo Codes](/promotions/promo-codes), select **Create**. **Generation Method: Manual**, **Code**: PARTNER10.
  </Step>
  <Step title="Set the discount">
    **Discount Type: Percentage**, **Discount Value**: 10.
  </Step>
  <Step title="Limit it">
    **Apply To: Specific ticket type**, pick the session and ticket. Turn on **Usage Limit** and enter 50.
  </Step>
</Steps>

{/* SCREENSHOT: images/tickets/promo-discounts-partner-form.png | Promotions > Promo Codes > Create, filled: Manual, PARTNER10, Percentage 10, Specific ticket type with General Admission, Usage Limit ON 50. Capture the whole panel. */}

## Other setups

- **Flash sale**: turn on **Time Limit** with start and end, **Apply To: All ticket types**.
- **Unique codes**: **Bulk Generate** up to 100 codes with an optional **Code Prefix**, and **Usage Limit** 1 for single-use.
- **Fixed amount**: **Discount Type: Fixed Amount**, such as $5 off.

{/* SCREENSHOT: images/tickets/promo-discounts-bulk-generate.png | Create Promo Code with Bulk Generate, Quantity 20, Code Prefix 'VIP', Usage Limit ON 1. */}

<Warning>
  A code for one ticket does not work on the others. For [release chain](/tickets/scenario-ga-tiers) tiers, choose **All ticket types** if the code should work on every tier.
</Warning>

## Check performance

Promo Codes shows **Uses/Limit**, **Revenue** and **Cost** per code, and **View Usage** lists each buyer. The [Ticket Report](/tickets/ticket-report) shows codes per order. To track channels rather than discount, see [Tracking Links](/promotions/tracking-links).
