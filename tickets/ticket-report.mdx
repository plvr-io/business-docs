The **Ticket Report** lists each ticket and add-on sold, with buyer, time and revenue.

<Frame>
  <img src="/images/tickets/ticket-report-summary-cards.svg" alt="Ticket Report summary cards for revenue, tickets sold, personalization progress and add-ons sold" />
</Frame>

The summary cards show revenue, tickets sold, personalization progress and add-ons sold. The last two only appear when your event uses them.

## Filter

<Frame>
  <img src="/images/tickets/ticket-report-filters.svg" alt="Ticket Report filters for Date, Session, Item and Search, with the Export button" />
</Frame>

- Use the **Start** and **End** date selectors to focus on a reporting period.
- **Session** only appears for multi-session events.
- Choose a session before an **Item**. Changing the session clears the item.
- **Search** matches buyer email, including partial matches.

## Read the table

<Frame>
  <img src="/images/tickets/ticket-report-table.svg" alt="Ticket Report table with promo and affiliate codes, a bundle, personalization icons and rows per page" />
</Frame>

Each row is one ticket or add-on. Add-ons are labeled, and bundle tickets show the bundle name. For events that need personalization, a warning icon means **Personalization Required** and a green check means **Personalized**.

The table includes:

- **Transaction details:** date and time, buyer, ticket type, revenue and payment method.
- **Promo Code and Affiliate Code:** identify the promotion or affiliate associated with a sale.

## Export

**Export** downloads a CSV of the current filters, so apply a date range, session, item or search first.

To see what drives sales, check the **Promo Code** and **Affiliate Code** columns. See [Promo Codes](/promotions/promo-codes) and [Affiliates](/promotions/affiliates).
