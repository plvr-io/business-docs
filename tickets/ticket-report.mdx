title: "Ticket Report"
description: "See every ticket and add-on sold for your event, filter the list, and export it to CSV."
---

The **Ticket Report** page lists each ticket and add-on sold for an event, with who bought it, when, and how much it earned. Open it from the event's navigation.

## Summary cards

The cards at the top give a quick snapshot of the event:

- **Total Revenue**: revenue in the event currency.
- **Tickets Sold**: tickets sold out of the total available.
- **Personalization Progress**: personalized tickets out of the tickets that require personalization. This card only appears when the event requires personalization.
- **Add-ons Sold**: add-ons sold out of the total available. This card only appears when the event has add-ons.

## Filter the report

Use the filters above the table to narrow the list. On small screens they sit behind a filter button.

| Filter | What it does |
| --- | --- |
| **Date** | Choose a **Start** and **End** date to show only orders placed in that range. |
| **Session** | Show one session only. This filter only appears when the event has more than one session. If the event has a single session, it is selected for you. |
| **Item** | Show one ticket type or add-on. Choose a session first, then pick an item from it. Changing the session clears the item. |
| **Search** | Type a buyer's email address. Partial matches work. |

{/* SCREENSHOT: images/tickets/ticket-report-filters.png | Ticket Report filters row on a multi-session event with the Session chosen and an Item selected. Capture Date (Start/End), Session, Item, Search and the Export button. */}

## Read the table

Each row is one ticket or add-on. The table shows:

- **Date & Time**: when the order was placed.
- **User**: the buyer's name and email. A small country flag appears next to the name when the order's country is known. Hover over it to see the country name.
- **Session**: the session the ticket belongs to. Hidden when the event has only one session.
- **Item**: the ticket or add-on name. Add-ons are labeled **Add-on**, and tickets bought as part of a bundle show the bundle name underneath.
- **Promo Code**: the promo code used, if any.
- **Revenue**: revenue for that item, with the event currency in the column header.
- **Affiliate Code**: the affiliate code attached to the order, if any.
- **Payment Method**: how the buyer paid.

For events that require personalization, an icon beside the item name shows the status:

- A yellow warning icon means **Personalization Required**.
- A green check icon means **Personalized**.

Use **Rows per page** (10 to 50) and the page arrows at the bottom of the page to move through the list. The total number of items is shown on the bottom left.

## Export to CSV

Select **Export** to download the report as a CSV file. The export respects the filters you have set, so apply a date range, session, item, or email search first if you only want part of the data. While the file is being prepared, the button reads **Exporting...**.

<Tip>
  To see which promo codes or affiliates are driving sales, filter by item and check the **Promo Code** and **Affiliate Code** columns, or see [Promo Codes](/promotions/promo-codes) and [Affiliates](/promotions/affiliates).
</Tip>
