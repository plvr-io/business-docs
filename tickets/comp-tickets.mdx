Use **Complimentary Tickets** to give free tickets to guests, sponsors, press or staff. They count against your ticket inventory like any other ticket.

{/* SCREENSHOT: images/tickets/comp-tickets-list.png | Complimentary Tickets page with about 5 issued comps (one still 'Generating...'). Callouts: 1 summary cards, 2 search box, 3 Create Complimentary Tickets button, 4 download icon at the end of a row. */}

Search by name or email, and sort by any column heading. Use the download icon to get a recipient's tickets as PDFs. A row showing **Generating...** is still being prepared, so check back shortly.

## Single Creation

Select **Create Complimentary Tickets**, then use the **Single Creation** tab.

{/* SCREENSHOT: images/tickets/comp-tickets-single-form.png | Create Complimentary Tickets > Single Creation, filled: Email ticket ON, Name 'Alex Rivera', Email 'alex@example.com', Session and Ticket Type chosen, Quantity 2, Remarks 'Press'. Use an event with a sold-out ticket type so the greyed-out option shows. Callouts: 1 email switch, 2 Ticket Type, 3 Quantity. */}

- Name and a valid email are required.
- Sold-out ticket types are greyed out.
- Quantity is up to 50 and never more than what remains.
- **Email ticket to recipient** only works for quantities of 10 or fewer.
- **Remarks** (up to 200 characters) are for your own reference.

## Bulk Creation

Issues one ticket type to up to **50 recipients** at once.

{/* SCREENSHOT: images/tickets/comp-tickets-bulk-form.png | Create Complimentary Tickets > Bulk Creation with a Ticket Type and 3 recipient rows. Callouts: 1 recipient counter (x/50), 2 'Qty (Max ...)' heading, 3 Total Tickets and Remaining, 4 Save. */}

<Steps>
  <Step title="Pick delivery and ticket">
    Choose whether to email the tickets, then the **Session** and **Ticket Type**.
  </Step>
  <Step title="Add recipients">
    Add rows or import a CSV. Each needs a name, email and quantity.
  </Step>
  <Step title="Check quantities">
    The max per recipient is 50, or 10 when emailing, and lower if fewer tickets remain. If the total exceeds what remains, you are asked to adjust.
  </Step>
  <Step title="Save">
    **Remarks** apply to the whole batch.
  </Step>
</Steps>

### Import from CSV

Use **Upload CSV**, or paste rows and select **Parse & Preview**. **Download Template** gives you a starting file. Columns, in order:

```csv
Name,Email,Quantity
John Doe,john@example.com,1
```

- A header row is optional. Names cannot contain commas.
- If a row is invalid, the import stops and names the line to fix.
- Imported rows count toward the 50 limit and can be edited before saving.
