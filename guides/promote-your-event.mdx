| See which channel brings buyers | [Tracking links](/promotions/tracking-links) |
| Reward partners per ticket sold | [Affiliates](/promotions/affiliates) |
| Message ticket holders, followers or your list | [Email campaigns](/promotions/campaigns) |
| Sell at the venue by QR code | [Door sales](/promotions/door-sales) |

<Tip>
A promo code changes the price. A tracking link only measures. Combine them, for example a tracking link in a newsletter with a code inside it.
</Tip>

## Example plan: two-day festival, on sale in six weeks

<Steps>
  <Step title="Week 0: prepare">
    - Promo code EARLYBIRD, a percentage off the first tier, **Usage Limit** 200.
    - One tracking link per channel (Instagram, newsletter, partner page), same **Campaign** name, each saved to history.
    - Enroll in **Affiliates** and set commissions for your promoters.
  </Step>
  <Step title="Week 1: announce">
    Post the Instagram link and email your list with an **Event Page** button. Give each promoter a link with their **Affiliate ID**.
  </Step>
  <Step title="Weeks 2 to 5: adjust">
    Check **Link History** and the [Ticket Report](/tickets/ticket-report). Fix weak channels. Email **Interested (No Purchase)** followers with a **Time Limit** code.
  </Step>
  <Step title="Last week: final push">
    Email **Ticket Holders** practical details, and print the door poster.
  </Step>
</Steps>
