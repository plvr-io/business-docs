The portal gives you four promotion tools, plus a door sales poster for the venue. Each answers a different question, so most events use more than one.

## Which tool should I use?

| You want to... | Use | Where |
| --- | --- | --- |
| Give buyers a discount | [Promo codes](/promotions/promo-codes) | **Promotions > Promo Codes** |
| Find out which channel brings visitors and buyers | [Tracking links](/promotions/tracking-links) | **Promotions > Tracking Links** |
| Reward partners or sellers for each ticket sold | [Affiliates](/promotions/affiliates) | **Promotions > Affiliates** |
| Message ticket holders, followers or your own list | [Email campaigns](/promotions/campaigns) | **Promotions > Campaigns** |
| Sell tickets at the venue by QR code | [Door sales](/promotions/door-sales) | **Promotions > Door Sales** |

<Tip>
A discount and a measurement are different jobs. A promo code changes the price. A tracking link only measures. You can use both together, for example a tracking link in a newsletter and a code inside it.
</Tip>

## How each one works in practice

<AccordionGroup>
  <Accordion title="Promo codes: a discount you control">
    Choose a percentage or fixed amount, limit it to certain ticket types, and cap it with a **Usage Limit** or **Time Limit**. Use **Bulk Generate** to make up to 100 codes at once, for example one per partner. Each code shows its **Uses/Limit**, **Revenue** and **Cost**, and **View Usage** lists who used it.
  </Accordion>
  <Accordion title="Tracking links: which channel works">
    Pick a **Channel** and sub-channel, give the **Campaign** a consistent name, and select **Save to History**. Only saved links count clicks. **Link History** shows **Clicks** and **Unique Clicks** for each link. Clicks show interest, not sales.
  </Accordion>
  <Accordion title="Affiliates: pay per ticket sold">
    Enroll the event once, then set a commission for each ticket type, as a percentage or a fixed amount. Enrollment cannot be undone. To follow a partner's results, create a tracking link with their **Affiliate ID**. Affiliate codes show up in the **Ticket Report**.
  </Accordion>
  <Accordion title="Email campaigns: talk to people you already reach">
    Send to **Ticket Holders**, **Pending RSVPs**, **Interested (No Purchase)**, or your own uploaded list. Each event has a weekly limit on blasts, shown as **Remaining Blasts**, so plan your sends. Sent campaigns show **Open Rate**, **Click Rate** and **Revenue**.
  </Accordion>
</AccordionGroup>

## Example campaign plan

A two-day music festival goes on sale in six weeks. Here is one way to use the tools together.

<Steps>
  <Step title="Before announcing (week 0)">
    - Create a promo code `EARLYBIRD` as a percentage discount, limited to the first ticket tier with a **Usage Limit** of 200.
    - Build one tracking link per channel: Instagram, a newsletter, and a partner's page. Use the same **Campaign** name, such as `launch_oct`, for all of them, and save each to history.
    - Enroll in **Affiliates** and set a fixed commission on each ticket type for the two promoters helping you sell.
  </Step>
  <Step title="Announcement (week 1)">
    - Post the Instagram link. Send your own list an email campaign with an **Event Page** button so clicks and revenue are tracked.
    - Share the promoters' tracking links, each with that promoter's **Affiliate ID**.
  </Step>
  <Step title="Mid campaign (weeks 2 to 5)">
    - Check **Link History** and the **Ticket Report**. If one channel brings clicks but no sales, adjust the message. If a code is nearly used up, decide whether to create another.
    - Email **Interested (No Purchase)** followers a reminder, with a time-limited code made with **Time Limit**.
  </Step>
  <Step title="Final push (last week)">
    - Email **Ticket Holders** with practical details, and **Interested (No Purchase)** followers with a last reminder.
    - Print the door sales poster so walk-ups can scan and buy on the day. See [Event day runbook](/guides/event-day-runbook).
  </Step>
</Steps>

<Note>
Keep an eye on **Remaining Blasts**. Plan your sends ahead and use **Send test** before each one.
</Note>

## Measure what worked

After the campaign, compare channels in **Link History**, codes in **Promo Codes**, and partners in the **Ticket Report**. See [After the event](/guides/after-the-event).
