---
title: "Launch checklist"
description: "Take an event from draft to live, in order."
---

Work through this the week before sales open, checking each result as a buyer would.

<Note>
Creating an event is not self-service yet. See [Events overview](/events/overview).
</Note>

## 1. Event page

In **Event Editor**, fill the required items (main image, name, start and end, About), then add gallery, **Terms and Conditions** and **Checkout consent**. Select **Save Event**, because nothing publishes until you do. See [Event editor](/events/event-editor).

<Check>Date, location and venue under the name are right. They are not editable here, so raise changes with PLVR.</Check>

{/* SCREENSHOT: images/guides/launch-event-editor.png | Event Editor for a draft event. Callouts: 1 required items (Main image, Event name, Start/End, About), 2 Terms and Conditions, 3 Checkout consent, 4 Save Event. */}

## 2. Tickets

In [Ticket Management](/tickets/ticket-management):

1. Check **Price**, **Total Quantity** and sale dates.
2. Set purchase limits if needed.
3. Make the tickets you want visible **Active**.
4. For tiers, set up a **Release Chain** with **Auto-release** on.
5. Create **Add-ons**.

<Warning>
Name and **Price** lock after the first sale.
</Warning>

{/* SCREENSHOT: images/guides/launch-ticket-management.png | Ticket Management on a ready-to-launch event: tickets with prices, dates and status (one starting in the future), the Release Chains header and the Add-ons tab. */}

## 3. Registration form

In [Registration Form](/events/registration-form), mark **Required** only what you need, since every extra question costs sign-ups. Name and email are always collected. Tap events also need the **Personalization Form** ([setup](/guides/cashless-festival-setup)). To approve attendees yourself, use [RSVP](/events/rsvp).

{/* SCREENSHOT: images/guides/launch-registration-form.png | Registration Form with Phone Number (Required), Date of Birth and one custom question. Callouts: 1 Quick add, 2 Custom question, 3 Required toggles. */}

## 4. Other ways to sell

- [Complimentary tickets](/tickets/comp-tickets) for sponsors and press.
- [Payment links](/other/payment-links) for one-off sales. Each link is single-use and expires after 24 hours.
- Promo codes, tracking links and the door poster: see [Promote your event](/guides/promote-your-event).

## 5. Go live

In the **Events** list, set the event's status to **Public**.

<Warning>
An **Ended** event is locked and its status cannot change.
</Warning>

{/* SCREENSHOT: images/guides/launch-events-status-menu.png | Events list with the status menu open on the event and 'Public' selected. */}
