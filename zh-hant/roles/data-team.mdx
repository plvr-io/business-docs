適合負責對帳與回報活動成果的人。大部分報表都可以匯出。

| 問題 | 查看位置 |
| --- | --- |
| 活動賣得如何？ | [活動總覽](/zh-hant/events/overview) |
| 誰買了哪種票券或加購項目？ | [票券報表](/zh-hant/tickets/ticket-report) |
| 每組優惠碼的成效如何？ | [優惠碼](/zh-hant/promotions/promo-codes) |
| 哪些管道與行銷活動帶來營收？ | [追蹤連結](/zh-hant/promotions/tracking-links)、[電子郵件行銷活動](/zh-hant/promotions/campaigns) |
| 每個商家賣了什麼？我們要付多少？ | [消費報表](/zh-hant/tap/spending-report) |
| 每一筆儲值與消費？ | [無現金交易紀錄](/zh-hant/tap/cashless-activity) |
| 服務台有沒有未完成的儲值？ | [無現金（現場營運）](/zh-hant/onsite/cashless) |
| 誰支付了自訂金額？ | [付款連結](/zh-hant/other/payment-links) |
| 誰會再回來？ | [受眾](/zh-hant/organization/audience) |

無現金相關頁面只會出現在使用 [PLVR Tap](/zh-hant/tap/introduction) 的活動中。

## 建議流程

<Steps>
  <Step title="售票期間">
    關注[總覽](/zh-hant/events/overview)，並匯出[票券報表](/zh-hant/tickets/ticket-report)。
  </Step>
  <Step title="活動當天">
    追蹤[無現金交易紀錄](/zh-hant/tap/cashless-activity)，並在[無現金](/zh-hant/onsite/cashless)中處理儲值問題。
  </Step>
  <Step title="活動結束後">
    從[消費報表](/zh-hant/tap/spending-report)匯出資料，並檢查付款連結。
  </Step>
  <Step title="收尾">
    依照[活動結束後](/zh-hant/guides/after-the-event)進行。
  </Step>
</Steps>

經理、管理員與擁有者都能開啟這些頁面。請參閱[依團隊的指南](/zh-hant/roles)。
