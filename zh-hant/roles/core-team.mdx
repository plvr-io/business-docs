核心團隊負責設定組織、建立每一場活動並讓它上線。擁有者與管理員可以開啟 **Team**（團隊）。經理則能使用其他所有功能，包括 **Organization**（組織）、**Table Booking**（訂桌）與所有活動頁面。

## 你需要的頁面

| 頁面 | 用途 |
| --- | --- |
| [組織設定](/zh-hant/organization/settings) | 管理你的主辦方公開頁面。 |
| [團隊與角色](/zh-hant/organization/team) | 新增成員，並選擇 Admin、Manager 或 Scanner。 |
| [活動總覽](/zh-hant/events/overview) | 變更公開狀態並查看銷售。 |
| [活動編輯器](/zh-hant/events/event-editor) | 打造公開的活動頁面。 |
| [票券管理](/zh-hant/tickets/ticket-management) | 價格、數量、販售期間、加購項目。 |
| [招待票](/zh-hant/tickets/comp-tickets) | 發放免費票券。 |
| [報名表單](/zh-hant/events/registration-form) | 結帳問題。 |
| [RSVP](/zh-hant/events/rsvp) | 核准或拒絕申請。 |
| [訂桌](/zh-hant/other/table-booking) | 場地桌位。 |
| [現場人員](/zh-hant/onsite/onsite-staff) | 活動當天團隊的登入碼。 |

使用 PLVR Tap 嗎？請參閱[總覽](/zh-hant/tap/introduction)與[無現金音樂節設定](/zh-hant/guides/cashless-festival-setup)。

## 建議流程

<Steps>
  <Step title="設定組織與團隊">
    先完成[組織設定](/zh-hant/organization/settings)，再處理[團隊與角色](/zh-hant/organization/team)。
  </Step>
  <Step title="了解票券">
    閱讀[票券概念](/zh-hant/tickets/concepts)，並參考[分階段一般入場票](/zh-hant/tickets/scenario-ga-tiers)與[多日音樂節](/zh-hant/tickets/scenario-multi-day-festival)中的範例。
  </Step>
  <Step title="建立活動">
    [活動編輯器](/zh-hant/events/event-editor)、[票券管理](/zh-hant/tickets/ticket-management)、[報名表單](/zh-hant/events/registration-form)。
  </Step>
  <Step title="上線與宣傳">
    依照[上線檢查清單](/zh-hant/guides/launch-checklist)與[宣傳你的活動](/zh-hant/guides/promote-your-event)進行。將宣傳工作交給[行銷團隊](/zh-hant/roles/marketing-team)。
  </Step>
  <Step title="準備活動當天">
    建立工作人員代碼，並依照[活動當天執行手冊](/zh-hant/guides/event-day-runbook)進行。
  </Step>
  <Step title="收尾">
    使用[活動結束後](/zh-hant/guides/after-the-event)。
  </Step>
</Steps>

第一次使用後台？請從[快速入門](/zh-hant/getting-started/quickstart)開始。

## 好習慣

- 掃碼人員只給 **Scanner**，**Admin** 只保留給負責管理團隊的人。
- 成員離開時就將他們移除。
- 如果你把自己的角色改成無法開啟 Team 的角色，可能會立即失去存取權限。
