## 各組織角色的存取權限

擁有者是建立組織的人。若要新增成員或變更角色，請參閱[團隊與角色](/zh-hant/organization/team)。

{/* SCREENSHOT: images/roles/roles-header-as-scanner-vs-owner.png | Two header crops stacked, labelled: the portal header as an Owner (Events, Table Booking, Audience, Team, Organization all visible) and as a Manager (no Team link). Crop each to the header bar only. */}

| 頁首連結 | Owner（擁有者） | Admin（管理員） | Manager（經理） | Scanner（掃碼員） |
| --- | --- | --- | --- | --- |
| **Events**（活動） | 是 | 是 | 是 | 是 |
| **Audience**（受眾） | 是 | 是 | 是 | 是 |
| **Table Booking**（訂桌） | 是 | 是 | 是 | 否 |
| **Organization**（組織） | 是 | 是 | 是 | 否 |
| **Team**（團隊） | 是 | 是 | 否 | 否 |

Scanner 角色用於在 PLVR Scan 中掃描票券，因此他們大部分的工作都在後台之外進行。

<Note>
  活動現場的入口、手環與儲值人員則改用登入碼登入。請參閱[現場人員](/zh-hant/onsite/onsite-staff)與[掃碼團隊](/zh-hant/roles/scanning-team)。
</Note>

第一次使用後台？請參閱[後台導覽](/zh-hant/getting-started/portal-tour)或[快速入門](/zh-hant/getting-started/quickstart)。若想依活動時間軸查看，請參閱[依階段的指南](/zh-hant/phases)。
