The **Affiliates** page lets you reward PLVR Affiliates for selling your tickets. You enroll the event once, then set a commission for each ticket type.

## Enroll your event

Select **Enroll** at the top of the page. Once enrolled, the button reads **Enrolled** and a confirmation appears.

<Warning>
  Affiliate enrollment cannot be disabled once you are enrolled. Until you enroll, the commission settings stay greyed out.
</Warning>

## Commission settings

The **Commission Settings** table lists the commissions you have set up:

| Column | Description |
| --- | --- |
| **Ticket Type** | The ticket the commission applies to. |
| **Price** | The ticket price, in the event currency. |
| **Commission Status** | **Active** or **Inactive**. Change it from the dropdown. |
| **Commission Type** | **Percent** or **Fixed**. |
| **Amount/Ratio** | The percentage, or the fixed amount. |
| **Commission** | The commission worth per ticket, worked out from the price. |

Before you add any, the table shows "No commissions configured. Click Create to add one."

## Add a commission

<Steps>
  <Step title="Select Create">
    Select **Create** below the table. The **Add Commission** panel opens. **Create** is turned off once every ticket type has a commission.
  </Step>
  <Step title="Choose the ticket">
    Pick a **Ticket Type**. Tickets that already have a commission are not offered. The ticket price is displayed under the field.
  </Step>
  <Step title="Choose the commission type">
    Select **Percent (%)** or **Fixed Amount** in the event currency.
  </Step>
  <Step title="Enter the amount">
    For a percentage, enter a whole number up to 100. The page recommends 1 to 40%. For a fixed amount, enter an amount above zero, with at most two decimal places (whole numbers only for currencies without decimals).
  </Step>
  <Step title="Create">
    Select **Create** to save.
  </Step>
</Steps>

## Edit a commission

Open the menu at the end of a row and select **Edit** to open **Edit Commission**. Change the type or amount and select **Save Changes**. To pause a commission, set its **Commission Status** to **Inactive**.

<Tip>
  To track partners with your own links, create a [tracking link](/promotions/tracking-links) with an affiliate ID. Affiliate codes also appear in the [Ticket Report](/tickets/ticket-report).
</Tip>
