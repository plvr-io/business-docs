Offer percentage or fixed-amount discounts. Create codes one at a time or generate many at once.

The list shows usage against each code's limit, plus revenue and cost. Change a code's **Status** right in the table, or select **Export CSV** to download the list.

## Create a promo code

Select **Create**.

<Steps>
  <Step title="Pick a method">**Manual** for one code you type, or **Bulk Generate** for up to 100 codes with an optional prefix.</Step>
  <Step title="Set the discount">Choose **Percentage** or **Fixed Amount** and enter the value.</Step>
  <Step title="Choose what it applies to">All ticket types, or a specific session and ticket.</Step>
  <Step title="Add limits (optional)">Turn on **Usage Limit** (maximum orders) and/or **Time Limit** (start and end). Without them the code never runs out or expires.</Step>
  <Step title="Save">**Description** is shown in the list, and **Remarks** are for your own notes.</Step>
</Steps>

{/* SCREENSHOT: images/promotions/promo-codes-create-panel.png | Click Create to open 'Create Promo Code'. Choose Manual, Code SPRING20, Percentage 20, Apply To 'Specific ticket type', Usage Limit ON (50) and Time Limit ON with dates. Capture the whole panel (scroll-stitch if needed). */}

## Edit, clone, or view usage

Use the menu at the end of a row.

- **Edit**: change settings or switch the code on or off. The code text cannot be changed.
- **Clone**: start a new code with the same settings.
- **View Usage**: see each order that used the code.

{/* SCREENSHOT: images/promotions/promo-codes-usage-log.png | On a code with some usage, capture the row menu (Edit, Clone, View Usage) and the Usage Log it opens. */}

<Tip>
  To see promo codes on individual orders, add the **Promo Code** column in the [Ticket Report](/tickets/ticket-report).
</Tip>
