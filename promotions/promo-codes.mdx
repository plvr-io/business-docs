**Promo Codes** let you offer percentage or fixed-amount discounts on your tickets. You can create codes one at a time or generate many at once.

## Summary cards

The cards at the top show **Tickets Sold**, **Revenue**, and **Cost** across your promo codes.

## The promo code list

Search codes with **Search promo codes**. The table shows:

- **Code**: the code text, with a copy button.
- **Description**: your description, or a dash when empty.
- **Discount Type** and **Discount**: percentage or fixed amount, and its value.
- **Uses/Limit**: how many times the code has been used out of its limit, for example `12/50`, or `Unlimited`. Select the heading to sort.
- **Apply to**: **All ticket types**, or the specific session and ticket. Select the heading to sort.
- **Revenue** and **Cost**: money tied to orders that used the code, with the event currency in the heading. Select either heading to sort.
- **Status**: **Active** or **Inactive**. Change it right from the dropdown.

## Create a promo code

Select **Create** to open the **Create Promo Code** panel.

<Steps>
  <Step title="Choose how to generate codes">
    Choose a **Generation Method**: **Manual** to type one code yourself, or **Bulk Generate** to create many at once.
  </Step>
  <Step title="Name the code or set bulk options">
    For **Manual**, enter the **Code** (required). For **Bulk Generate**, enter a **Quantity (Max. 100)** from 1 to 100, and an optional **Code Prefix**, such as "PLVR". Codes are generated for you.
  </Step>
  <Step title="Set the discount">
    Pick a **Discount Type**: **Percentage** or **Fixed Amount**. Then enter the **Discount Value**. A percentage must be a positive whole number. A fixed amount is in the event currency (whole numbers only for currencies without decimals, otherwise up to two decimal places).
  </Step>
  <Step title="Choose what it applies to">
    **Apply To** is **All ticket types** or **Specific ticket type**. For a specific type, choose the session and ticket under **Ticket Type**.
  </Step>
  <Step title="Add limits (optional)">
    Turn on **Usage Limit** and enter the **Maximum transactions allowed for this code**, a positive whole number. Turn on **Time Limit** to set a start and end date and time. Without a limit, the code has no cap or no expiry.
  </Step>
  <Step title="Add a description and remarks, then save">
    **Description** is optional. **Remarks** is for your own notes. Save to create the code.
  </Step>
</Steps>

## Edit, clone, or view usage

Open the menu at the end of a row:

- **Edit**: change a code's settings. The code text itself cannot be changed. When editing, a **Status** switch lets you turn the code on or off.
- **Clone**: opens **Create Promo Code** pre-filled with the same settings, with an empty code, so you can make a similar one quickly.
- **View Usage**: opens the **Usage Log** for that code. It shows the number of uses against the limit, and a table of **Buyer**, **Tickets** and **Date & Time** for each order. A **Session** column appears for events with several sessions.

</Tip>
