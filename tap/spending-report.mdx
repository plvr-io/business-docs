---
title: "Spending report"
description: "Review sales by vendor and by item, and export summaries and vendor settlement reports."
---

The **Spending Report** shows how much was spent at your event, broken down by vendor and by item. Find it under **PLVR Tap** in the event sidebar. It only appears for events with PLVR Tap enabled.

## Tabs

- **By Vendor:** one row per vendor.
- **By Item:** one row per item, with the vendor's name underneath.

Use **Search** to filter: by vendor name on the By Vendor tab, or by vendor name or item name on the By Item tab. The table is paged, 10 rows per page.

A pinned **Total** row at the top adds up everything that matches your search, not only the current page.

## Columns

Hover the info icon on a column for its definition. Amounts use the event currency.

**By Vendor**

| Column | Meaning |
| --- | --- |
| **Successful Txns** | Number of successful spending transactions. |
| **Cancelled Txns** | Number of cancelled spending transactions. |
| **Gross Sales** | Original transaction amount before refunds. |
| **Refunded Amount** | Amount refunded from the transaction. |
| **Net Sales** | Gross Sales minus Refunded Amount. |

**By Item**

| Column | Meaning |
| --- | --- |
| **Net Items Sold** | Items sold after refunded quantities are deducted. |
| **Gross Sales**, **Refunded Amount**, **Net Sales** | Same as above, for that item. |

## Exports

Exports download as Excel files.

- **Export Summary** exports the current tab (vendor summary or item summary), using your search.
- **Export Report** on a vendor row downloads that vendor's settlement report. Use it when settling with the vendor.
- **Export All Vendor Reports** (By Vendor tab) prepares one report per vendor for the whole event. A progress label shows while it runs, and the files download when ready.

<Note>
If a report can't be loaded or exported, a message appears. Try again, or use **Retry** on the table.
</Note>
