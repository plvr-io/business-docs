Vendors are the stalls that charge attendees by scanning wristbands. Find **Vendor Setup** under **PLVR Tap** in the event sidebar.

<Frame>
  <img src="/images/tap/tap-vendor-list.svg" alt="Vendor Setup list with the Add Vendor button" />
</Frame>

## Add a vendor

<Steps>
  <Step title="Add Vendor (1)">Select it to open the form.</Step>
  <Step title="Fill in the details">A name is required. Image, internal note, and status are optional.</Step>
  <Step title="Create Vendor">Click the vendor name to open it.</Step>
</Steps>

<Frame>
  <img src="/images/tap/tap-vendor-create-panel.svg" alt="Create Vendor panel" />
</Frame>

<Note>
Inactive vendors, sales locations, and items are unavailable for login and new orders. Items in an inactive category are unavailable everywhere.
</Note>

## Set up a vendor

<Frame>
  <img src="/images/tap/tap-vendor-detail-tabs.svg" alt="Vendor page with Sales Locations, Items and Login Codes tabs" />
</Frame>

<Steps>
  <Step title="Sales Locations">Add each place the vendor sells, such as "Main Bar".</Step>
  <Step title="Items">Add categories and items. Each item needs a price above 0 and at least one sales location.</Step>
  <Step title="Login Codes">Generate 1 to 200 codes at once. A note applies to the whole batch.</Step>
</Steps>

<Frame>
  <img src="/images/tap/tap-vendor-add-item-form.svg" alt="Create Item panel with sales locations selected" />
</Frame>

Items and categories that vendors submit themselves go through [Approvals](/tap/approvals) first. Use **Export** on the Items and Login Codes tabs to download a CSV.

<Frame>
  <img src="/images/tap/tap-vendor-login-codes.svg" alt="Create Vendor Login Code panel" />
</Frame>

<Warning>
Inactive login codes cannot sign in. Set a code to Inactive if someone leaves the stall or a code is shared by mistake.
</Warning>
