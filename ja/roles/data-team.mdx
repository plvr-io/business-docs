売上の照合や、イベントの成果報告を担当する方向けです。ほとんどのレポートはエクスポートできます。

| 知りたいこと | 確認する場所 |
| --- | --- |
| イベントの販売状況は？ | [イベントの概要](/ja/events/overview) |
| 誰がどのチケットやアドオンを購入したか？ | [チケットレポート](/ja/tickets/ticket-report) |
| 各プロモコードの成果は？ | [プロモコード](/ja/promotions/promo-codes) |
| どのチャネルやキャンペーンが売上につながったか？ | [トラッキングリンク](/ja/promotions/tracking-links)、[メールキャンペーン](/ja/promotions/campaigns) |
| 各出店者の販売額と、支払うべき金額は？ | [利用額レポート](/ja/tap/spending-report) |
| すべてのチャージと支出の明細は？ | [キャッシュレス取引履歴](/ja/tap/cashless-activity) |
| 受付デスクで未解決のチャージはあるか？ | [キャッシュレス（Onsite Operations）](/ja/onsite/cashless) |
| 任意の金額を支払ったのは誰か？ | [支払いリンク](/ja/other/payment-links) |
| リピートしているのは誰か？ | [オーディエンス](/ja/organization/audience) |

キャッシュレス関連のページは、[PLVR Tap](/ja/tap/introduction) を利用するイベントでのみ表示されます。

## おすすめの進め方

<Steps>
  <Step title="販売期間中">
    [概要](/ja/events/overview)を見守り、[チケットレポート](/ja/tickets/ticket-report)をエクスポートします。
  </Step>
  <Step title="イベント当日">
    [キャッシュレス取引履歴](/ja/tap/cashless-activity)を追い、[キャッシュレス](/ja/onsite/cashless)でチャージの問題を解決します。
  </Step>
  <Step title="イベント終了後">
    [利用額レポート](/ja/tap/spending-report)からエクスポートし、支払いリンクを確認します。
  </Step>
  <Step title="締めくくる">
    [イベント終了後](/ja/guides/after-the-event)に沿って進めます。
  </Step>
</Steps>

これらのページは、マネージャー、管理者、オーナーが開けます。[チーム別ガイド](/ja/roles)をご覧ください。
